# DriveFour

Four-bar drive desk for bedroom producers and AI-music finishers.

Suno and loop DAWs leave the pocket static on roots. Session players add kick pushes, open hats, and bass anticipations so the four bars drive forward and the track can finish.

Live samples only — FluidR3 acoustic grand, upright bass, nylon guitar, trumpet, violin, and acoustic kit from the PreEight bank pinned to commit `d58301e4a494555f411a2afbc448b724136eee76`.

No oscillators. Audio never leaves the tab.
